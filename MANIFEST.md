# Манифест репы `claude-usage`

## 1. Что это за репа — в трёх предложениях

Инструмент, отвечающий на вопросы, которые `/usage` не отвечает: как растёт контекст,
сколько стоит ход при 300K против 25K, когда сбросится лимит, что лог **не может**
сказать. Читает локальные логи сессий (`~/.claude/projects/*.jsonl`), без сети и
зависимостей. Публичная витрина навыка работы с логами и эмпирикой — личные данные
и внутренние протоколы базы сюда не попадают по построению (публичный периметр).

**Класс:** `product` · **Видимость:** 🌐 ПУБЛИЧНАЯ — 🔴 личное не кладётся никогда (`PIT-123`)
**Версия на момент манифеста:** см. `VERSION`

## 2. Описание для `.repo-meta` и GitHub

Where your Claude Code budget actually goes: context growth, cost per turn by
